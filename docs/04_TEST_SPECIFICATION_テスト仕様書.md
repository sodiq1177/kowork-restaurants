# テスト仕様書 (Test Specification)

**プロジェクト名**: CoWork Restaurant Portal  
**対象バージョン**: v2.0 Production Release  
**作成者**: Sodiq  
**テスト対象**: 全画面・全API・多言語・認証・データベース連携  

---

## 1. テスト環境 (Test Environment)
- **OS**: Windows 11 / macOS / iOS / Android (Responsive Mobile & Desktop)
- **ブラウザ**: Google Chrome (Latest), Mozilla Firefox, Safari, Microsoft Edge
- **本番環境**: Vercel Serverless Edge Platform (`https://kowork-restaurants.vercel.app`)
- **データベース**: Neon Serverless PostgreSQL (AWS us-east-2)

---

## 2. テストケース一覧表 (Test Case Matrix)

| No. | 対象機能 | テスト項目 / 手順 | 期待される動作 (Expected Result) | 重要度 |
|-----|----------|-------------------|----------------------------------|--------|
| **TC-01** | 多言語切替 (i18n) | 言語スイッチャーで UZ, EN, RU, JA を順に選択 | URLが `/[locale]/` に変わり、全テキストが即時に対象言語に切り替わること | 高 |
| **TC-02** | ユーザー登録 | `/register` から新規メールとパスワードで登録 | DBにユーザーが暗号化保存され、自動ログインまたはログイン画面へ遷移すること | 高 |
| **TC-03** | ユーザーログイン | 登録済みのメール・PWでログイン | セッションが発行され、Navbarにユーザー名とログアウトボタンが表示されること | 高 |
| **TC-04** | キーワード検索 | トップバー検索で "plov" または "pizza" を入力 | 該当するレストランカードのみが絞り込み表示されること | 高 |
| **TC-05** | カテゴリ・価格フィルタ | "Uzbek", "Italian" や "MODERATE" をクリック | 選択した条件に一致するレストランのみリアルタイムで表示されること | 中 |
| **TC-06** | 地図表示 (Map) | レストラン詳細画面で地図を確認 | Yandex Maps上に店舗の正確な位置ピンが表示され、拡大縮小が可能なこと | 高 |
| **TC-07** | 周辺検索 (GPS) | `/nearby` で位置情報の許可を与える | 現在地からの距離（km）が計算され、近い順にリスト表示されること | 高 |
| **TC-08** | レビュー投稿 | 星評価 (1-5) とコメントを入力して送信 | レビュー一覧に即時反映され、レストランの平均評価と件数が再計算されること | 高 |
| **TC-09** | お気に入り機能 | レストランカードのハートアイコンをクリック | `/favorites` 画面に追加され、再クリックで解除されること | 中 |
| **TC-10** | 管理者権限制御 | 一般ユーザーで `/admin` にアクセス試行 | アクセス拒否 (403/リダイレクト) され、Adminアカウントでのみ管理画面が表示されること | 高 |
| **TC-11** | 店舗CRUD (Admin) | 管理画面から新規レストランを登録・編集・削除 | PostgreSQL DBに正常に反映され、一覧・詳細画面で確認できること | 高 |
| **TC-12** | レスポンシブ表示 | スマートフォン画面幅 (375px) で各ページを表示 | ハンバーガーメニューが動作し、レイアウト崩れなく閲覧・操作できること | 高 |
